\section{Background}
\label{sec:background}

\subsection{From interoperability to arbitration}
Work on agent interoperability has moved through three stages. First, user interfaces sent one prompt to several models but shared no state. Second, protocols defined how agents exchange tasks and tool context: the Model Context Protocol connects an agent to tools and data~\cite{mcp2025}, and the Agent2Agent protocol defines task exchange between agents~\cite{a2a2025}. Third, memory layers stored agent output across sessions~\cite{packer2023memgpt,chhikara2025mem0,rasmussen2025zep,honcho2026}, and graph-based layers extracted entities from code~\cite{cognee2026}. These stages move context. None of them decides which context has authority. Bridge sits after these stages: it assumes that agents can exchange context, and it arbitrates conflicts in that context.

\subsection{Systems of record for authority}
Software teams already record authority in several places.
\begin{itemize}
    \item \textbf{CODEOWNERS.} GitHub reads a CODEOWNERS file from \texttt{.github/}, the repository root, or \texttt{docs/}, in that order. Each line maps a gitignore-style pattern to owners (users, teams, or email addresses). The last matching line wins, and a line without owners removes ownership~\cite{githubcodeowners}. Components with many minor contributors have more defects~\cite{bird2011ownership}, and expertise can be derived from change history~\cite{mockus2002expertise}.
    \item \textbf{Branch protection.} Protected branches require reviews, status checks, or signed commits before a merge~\cite{githubbranchprotection}.
    \item \textbf{Commit signatures.} Git verifies GPG and SSH signatures and reports a status per commit through the \texttt{\%G?} format: \texttt{G} (good), \texttt{U} (good, unknown validity), \texttt{X} and \texttt{Y} (expired signature or key), \texttt{R} (revoked key), \texttt{B} (bad), \texttt{E} (cannot check), and \texttt{N} (no signature)~\cite{gitlog}. Sigstore extends signing to keyless, identity-bound signatures~\cite{newman2022sigstore}.
    \item \textbf{Identity and delegation.} OAuth~2.0 delegates limited access to clients~\cite{rfc6749}, and SPIFFE issues workload identities~\cite{spiffe2026}. The NIST AI Risk Management Framework asks for accountability and transparency in AI systems~\cite{nist2023airmf}.
\end{itemize}
These records are imperfect. Authorship, history rewriting, and merges can hide who did what in Git data~\cite{bird2009git}. Bridge inherits these limits (Section~\ref{sec:framework-git}), but it adds no second copy that can drift from the first.
